# Locvel

Open source, privacy-first, local-first software.

**loc** — local. **vel** — veil.

Founded November 2026.

## Projects

- [**Voite**](https://github.com/locvel/voite) — Private, offline voice recorder and diary with on-device transcription. Free, no account, no server.
- [**.github**](https://github.com/locvel/.github) — This org's shared rules: code of conduct, security policy, contributing guide, AI policy, and governance.

## Get started

- Try Voite: [download the latest release](https://github.com/locvel/voite/releases/latest) (Android APK) or [watch the tutorial](https://youtu.be/El_ou_v5tWA).
- Read the docs: [Voite site](https://locvel.github.io/voite/) and the [Locvel home page](https://locvel.github.io/).

## Contribute

New here? Start with the [contributing guide](https://github.com/locvel/.github/blob/main/.github/CONTRIBUTING.md) and the [good first issues](https://github.com/locvel/voite/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22). Small fixes go straight to a pull request; bigger changes need an issue first. All contributions need a `Signed-off-by:` line (DCO). AI may assist, but you must understand and explain every change — see the [AI policy](https://github.com/locvel/.github/blob/main/.github/AI_POLICY.md).

## Security

Report vulnerabilities privately via GitHub Security Advisories (the "Report a vulnerability" tab on any Locvel repo) or by email to hello.locvel@gmail.com. Full policy: [SECURITY.md](https://github.com/locvel/.github/blob/main/.github/SECURITY.md). Only the latest release is supported with security fixes.
